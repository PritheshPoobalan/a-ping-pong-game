# Project structure

This document describes the repository layout. git ls-files reports 4103
tracked files in total, most of them inside large subprojects.

## Top-level files

- index.html — pong game page (title: Pripro Pong Game)
- game.js — pong game script
- style.css — pong game styles
- Controls.txt — control reference carried over from another project
- CNAME — GitHub Pages custom domain: priprostudios.js.org
- leaderboard.html — scoreboard page
- minecraftsec.html — Minecraft-related HTML page
- minecraftver2pripro101.html — Minecraft-related HTML page
- originalacesspointpublicminecraft.html — Minecraft-related HTML page

## Top-level directories (independent projects)

- CSS-Minecraft-main — CSS-based Minecraft clone (18 tracked files)
- DuckOS-main — DuckOS web operating system (89 tracked files)
- azuos-legacy-main — legacy operating system project (178 tracked files)
- chilibowlflash-main — Flash game collection, includes pong.html and pong.swf
  (2707 tracked files)
- games-gh-pages — HTML5 games collection (390 tracked files)
- html5-mobile-gameboy-master — Game Boy emulator (32 tracked files)
- icecapades-main — icecapades project (133 tracked files)
- iso — ISO-related assets
- v86-master — x86 PC emulator in JavaScript (545 tracked files)

Each subdirectory is self-contained. Open its index.html to run that project.
